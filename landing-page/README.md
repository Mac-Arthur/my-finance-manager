# myAvailable landing page

Standalone HTML, CSS and JavaScript. It does not need npm or a build command.

## Netlify

- For drag-and-drop deployment, upload this entire `landing-page` folder.
- For Git deployment, set the **base directory** to `landing-page`, leave the build command empty, and set the **publish directory** to `.`.
- The primary buttons currently open `https://my-available.macarthur83.workers.dev`. Replace that URL in `index.html` if the app domain changes.

## Local preview

Run a static server from this folder, for example:

```sh
npx serve .
```
