myAvailable reads supported statements on your device. This guide explains what currently works and how to fix common import problems.

Compatibility

Supported statements

Works now

  • MTN MoMo searchable PDF statements
  • Searchable bank PDFs with a recognisable transaction table
  • CSV with date, description and amount—or debit and credit columns
  • Password-protected PDFs when you know the password
  • Ghana cedis (GHS), up to 25 MB and 400 PDF pages

Needs another format

  • Scanned or photographed statements with no selectable text
  • PDF tables whose amount columns wrap or change layout
  • Other currencies
  • Provider layouts that cannot be reconciled safely
  • Telecel Cash and AT Money PDFs not yet validated with real samples

Troubleshooting

When an import does not work

“Page has no readable text”

The PDF is probably a scan. Download a searchable statement or CSV from the provider. Renaming an image to PDF will not add readable text.

“Could not recognise the transaction columns”

Use the CSV template above, or export a CSV containing a date, description and signed amount. Separate debit and credit columns also work.

The PDF asks for a password

Use the password instructions from the email that delivered the statement. The password is used once in this browser and is never saved.

The running balances do not add up

The app sends the file to review instead of silently trusting it. Check the extracted rows. If the source layout is unusual, use a CSV export.

Install the app

Keep myAvailable on your home screen

Android · Chrome

  1. Open the HTTPS myAvailable address in Chrome.
  2. Tap the three-dot menu.
  3. Choose Install app or Add to Home screen.
  4. Open it once, then test with airplane mode.

iPhone · Safari

  1. Open the HTTPS myAvailable address in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then Add.
  4. Launch it from the new home-screen icon.

Installation requires HTTPS. A browser's private mode may disable installation or local storage. Imported statements remain specific to the browser installation where you added them.
